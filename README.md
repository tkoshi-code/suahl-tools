# quiz-7flips

スアールのクイズイベントで使用する進行・ルール表示PWAです。Flip 7、カスタムスロットミリオネア、コーナー説明、告知スライド、休憩表示、Spotifyイントロクイズなどをまとめています。

## 公開サイト

https://tkoshi-code.github.io/quiz-7flips/

`master` ブランチへpushすると、GitHub Actionsが自動的にビルドしてGitHub Pagesへ公開します。

## 主な画面と機能

- ホーム: イベント情報とクイズコーナーの選択
- Flip 7: クイズ正解者がカードを引くゲーム
- カスタムスロットミリオネア: 最大3チームで、10問の正解数に応じてスピンし、カードでスロットを強化する対戦ゲーム
- Spotifyイントロクイズ: QM操作画面と会場表示
- 告知・休憩表示: 会場スクリーン向け表示

## カスタムスロットミリオネア

2〜3チーム、勝利VP（50 / 75 / 100）、カード検討時間（60 / 90 / 120秒）を設定します。

1. ゲーム開始時に全チームが1回ずつスピンする
2. 1ラウンド10問のクイズを行い、チームごとの正解数を記録する
3. 10問終了後、各チームが正解数とチャレンジ効果に応じた回数をまとめてスピンする
4. 全チームのスピン後、チーム数+1組の3枚カードセットを公開する
5. VPが低いチームから1セットずつ選ぶ。同点時はそのラウンドの正解数が少ないチームを先にする
6. 制限時間内に各チームが獲得カードを使用し、次の10問へ進む。時間終了後はカードを使用できない

初期数字山札は1×4枚、2×4枚、3×3枚、7×1枚です。共有のナンバーカードは「1/2」「3（+1VP）」「3（+2VP）」「7」が各8枚です。1/2は判定ラインごとに1または2として扱い、ボーナス付き3は揃わなくても盤面に出た枚数分のVPを得ます。

強化カードはリムーブ、ワンツービート、ラッキーナンバー、ビッグナンバー、スモールナンバー、リスクリターンです。倍率カードは横×1、縦×1・×2、斜め×1・×2を任意の対応ラインへ置きます。チャレンジカードは次ラウンドの「正解1問あたり2スピン」「追加2スピン」「指定チームのスピン権を2回無効」の3種です。

盤面上の実線が現在の有効ラインです。横・縦・斜めの各ライン状態、倍率、数字山札の内訳、カード効果、スピン結果内訳を画面で確認できます。3列は時間差で停止し、結果を確認してから次のスピンへ進みます。

勝利判定は全チームのラウンド内スピンが終わった時点で行います。複数チームが目標VPへ到達した場合はVPが最も高いチームを勝者とします。

ゲーム状態は `piyopiyo_custom_slot_v1` として自動保存されます。進行ログ欄からJSONバックアップと復元ができます。

## スマートフォンへの導入

公開サイトをSafariまたはChromeで開き、ブラウザメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。一度オンラインで読み込むと、Service Workerのキャッシュからオフライン起動できます。

## データ保存とバックアップ

入力・ゲームデータはブラウザのlocalStorageだけに保存し、自動送信しません。カスタムスロットとSpotifyイントロクイズは、それぞれの画面からJSONを出力・復元できます。ブラウザのサイトデータを削除する前に必要なJSONを保存してください。

詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

```sh
npm run dev -- --host 0.0.0.0
```

ブラウザで `http://127.0.0.1:5173/` を開きます。

```sh
npm run build
```

## Spotifyイントロクイズ

トップ画面下部の「ツール」からQM操作画面を開きます。

- Spotifyの曲共有URLと、会場に表示する答えを登録
- 3～30秒の指定時間だけ曲の先頭から再生して自動停止
- 未出題曲からランダムに次の曲を選択
- QM画面とは別の会場表示ウインドウへ、カウントダウンと答えを送信
- 登録曲をJSONでバックアップ・復元

Spotifyプレーヤーには曲名が表示されるため、QM操作画面は会場のスクリーンには映さず、「会場表示を開く」で開いたウインドウを使用してください。ブラウザの自動再生制限により音が出ない場合は、Spotifyプレーヤー内の再生ボタンを一度押します。

登録曲と再生時間は `piyopiyo_spotify_intro_v1` としてブラウザのlocalStorageに保存されます。Spotifyのアカウント情報やOAuthトークンは保存しません。再生時にはSpotifyの公式埋め込みプレーヤーへ通信します。

店舗イベントでの利用に必要な楽曲の権利とSpotifyの利用条件は、運営側で事前に確認してください。

### 初級スターターJSON

[public/data/spotify-intro-starter.json](public/data/spotify-intro-starter.json)を、答えやすいイントロ曲の共有カタログとして管理します。QM画面の「JSONから追加」を押すと、新しく追加された曲だけが端末へ追加されます。登録済みの曲や利用者が編集した答えは削除・上書きしません。

各曲にはSpotify URLのほか、`title`、`artist`、`difficulty`、`category`、`decade`、`recommendedSeconds`、`note`を持たせています。今後は同じ形式で曲を追加し、`catalogVersion`を更新します。
